# Neon Vice Cover Studio

Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

A multi-panel cover art maker: load your own photos, position them panel by
panel, pick a sunset or neon grade, edit the gradient title and caption, and
export a PNG at 1080x1080, 1080x1350 or 1920x1080. Everything runs locally in
the browser — photos never leave your machine.

Run `node serve.ts` and open http://localhost:8080.
